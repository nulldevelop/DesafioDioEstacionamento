Projeto console simples (desafio DIO) que simula um sistema de estacionamento. Permite:
- Adicionar veículos (`AdicionarVeiculo`)
- Remover veículos com cálculo do valor total (`RemoverVeiculo`)
- Listar veículos estacionados (`ListarVeiculos`)

Arquivos relevantes
- `Program.cs` — ponto de entrada da aplicação.
- `DesafioDioEstacionamento\Models\DesafioDioEstacionamento.cs` — classe `Estacionamento` com a lógica principal (preço inicial, preço por hora e lista de placas).

Tecnologia
- .NET 10
- Linguagem: C#
